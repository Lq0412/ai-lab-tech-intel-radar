# Lab 实习生招聘 · 笔试题目

## AI 技术情报雷达 · 方案设计

### 背景

某企业 AI Lab 需要搭建一个常态化的技术情报雷达——持续扫描 AI 社区动态、识别值得关注的资源（新模型、论文、开源工具、技术路线...），评测其工程价值与能力边界，输出给内部决策者作参考。

### 任务场景

Lab 团队 5-8 人，内部决策者每周要回答「这个新模型 / 框架 / 路线，值不值得我们投入资源跟进」这类问题，因此需要一个智能化系统帮助跟踪和评测，输出经验证的辅助决策报告。

请为这个雷达给出方案设计。该系统应该覆盖哪些能力 / 能力边界、是否使用 Agent 架构、是否使用某类技术、探测哪些信息源，均由自行判断并说明理由。

设计的雷达需满足：**4 周内由 1-2 个人落地可用 MVP**，后续可逐步演进。

### 交付物

3-5 页 Markdown 格式文档 + 1 张架构图，包含以下四部分：

1. **对题目本身的质疑与假设**：判断需求描述中不清晰、有歧义、不认同的内容，说明观点、背后假设及原因。
2. **方案设计**：1 张架构图 + 关键模块说明。
3. **关键设计决策**：解释设计背后的思考、取舍、假设。
4. **LLM 使用说明**：标注哪些内容由模型生成、人工修改内容及修改原因，列明过程中使用的模型和工具。

### 关于 LLM 使用

默认允许并鼓励使用 LLM 辅助完成；能产出出色答案的候选人，正是团队想要招募的人选。需清晰撰写「LLM 使用说明」，该内容本身属于考察项。

### 线上面试

通过初选的候选人将受邀参加 20 分钟视频面试，回答面试官针对方案设计提出的问题，可在过程中展示真实个人风格。

### 实习衔接

通过筛选的候选人可加入 AI Lab 实习；实习期首要任务为在一个月内落地实现该方案，作为 Lab 日常基础工具使用。

需将本次提案视作实际交付工作成果，而非单纯面试题目。

**任务时间：** 本周五下午 6 点之前
